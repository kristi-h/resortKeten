# Resort Keten

### Overview

Website for a getaway resort

### Features

Be guided though an extensive albumn of each of our villa offerings.

Take a peak into local culture, with our dedicated page for unique characteristics and activities.

Book your getaway online via our payment portal to reserve dates for your trip.

Contact us for more information or questions you may have.

### Running the project

1. Clone this project locally
2. cd into the project directory
3. To run the app on your local device, make sure to install the appropriate packages and run using the following command:
   npm install
   npm run dev
4. Book your next getaway!
